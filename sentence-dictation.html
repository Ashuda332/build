How to add more voices (and get better sound)

This app uses the voices already on your device. It does not need the internet. If an accent shows "not installed", add a voice for it, then reload this page.

Windows 10 / 11

  1. Open Settings → Time & language → Speech.
  2. Under Manage voices, click Add voices.
  3. Pick English (India), English (United Kingdom), etc. and install.
  4. Restart the browser.

Android

  1. Open Settings → Accessibility → Text-to-speech output (or search "text-to-speech").
  2. Choose Speech Services by Google, tap the gear icon → Install voice data.
  3. Download English (India) and other English voices.

iPhone / iPad

  1. Open Settings → Accessibility → Spoken Content → Voices → English.
  2. Download voices such as Rishi or Veena (India), Daniel (UK), Karen (Australia), Moira (Ireland), Tessa (South Africa).
  3. Pick the Enhanced or Premium versions for clearer sound.

Mac

  1. Open System Settings → Accessibility → Spoken Content.
  2. Click System voice → Manage Voices, then tick English voices for India, UK, Ireland and others.

Best-sounding voices

  • Microsoft Edge (Windows/Mac/Android) has very natural voices named "… Online (Natural)", for example Neerja and Prabhat for Indian English. They need the internet.
  • Chrome on a computer has "Google UK English" and "Google US English" voices. They also need the internet.
  • Voices marked (online) in the list need the internet. Other voices work offline.
